Política de privacidad

Última actualización: 4 de octubre de 2026

WatchTower es un centro personal para organizar y seguir series, anime y películas. WatchTower Companion es su extensión de navegador y Skipper es el módulo de automatización de reproducción integrado.

1. Datos procesados

La extensión puede procesar información visible de la página necesaria para sus funciones, como títulos mostrados, episodio o temporada, URL, porcentaje de progreso expuesto por la interfaz, tarjetas visibles de “Seguir viendo” y elementos visibles de listas personales como “Mi lista”, “Watchlist”, “My Stuff”, “My Queue” o equivalentes del servicio. En servicios protegidos, WatchTower no accede ni modifica el contenido de vídeo protegido, DRM/EME, contraseñas, cookies de autenticación, tokens de sesión ni datos de pago.

2. Streaming Importer

Cuando está activado, Streaming Importer puede leer únicamente metadatos que el propio servicio de streaming ya muestra en la página, por ejemplo el nombre de una serie, temporada, episodio, barras de progreso visibles y pertenencia visible a una lista personal. Esta información se usa para proponer, añadir como pendiente o actualizar entradas de la biblioteca de WatchTower. El usuario puede revisar, corregir, rechazar o bloquear cualquier detección automática. Streaming Importer no consulta el elemento de vídeo protegido ni intenta acceder al historial oculto de la cuenta.

3. Almacenamiento local

WatchTower puede guardar localmente biblioteca, progreso, preferencias, historial, estadísticas, configuración de Skipper, detecciones recientes del Streaming Importer y datos de diagnóstico. Estos datos se utilizan para proporcionar las funciones del producto.

4. Sincronización opcional

Si el usuario configura voluntariamente la sincronización en la nube, WatchTower puede usar un backend Supabase indicado por el propio usuario para sincronizar su estado y eventos entre dispositivos. La sincronización puede permanecer desactivada y el producto funciona con almacenamiento local.

5. Servicios externos

Algunas funciones de metadatos pueden consultar servicios de información de títulos configurados por el usuario. Las respuestas se utilizan como datos; WatchTower no descarga ni ejecuta código remoto desde esos servicios.

6. Venta y publicidad

WatchTower no vende datos personales ni los transfiere a redes publicitarias o corredores de datos. Los datos no se utilizan para crédito, préstamos ni finalidades ajenas a la funcionalidad declarada.

7. Contenido protegido

WatchTower y Skipper no descargan vídeos, no eluden DRM, no evitan paywalls ni inicios de sesión y no proporcionan acceso a contenido que el usuario no pueda reproducir por sí mismo.

8. Chrome Web Store

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

9. Contacto

Para soporte o cuestiones de privacidad, utiliza el correo de contacto del editor mostrado en la ficha oficial de WatchTower Companion en Chrome Web Store.
